# Python Calculator

A beginner-friendly calculator project built using Python.

## Features

- Addition, subtraction, multiplication and division
- Decimal calculations
- Graphical user interface using Tkinter
- Keyboard support
- Clear and backspace functions
- Division-by-zero protection
- Error handling

## Project Files

- `calculator.py` – Command-line calculator
- `gui_calculator.py` – Graphical calculator

## Requirements

- Python 3
- Tkinter (included with most standard Python installations)

## How to Run

Run the command-line calculator:

```bash
py calculator.py
```

Run the GUI calculator:

```bash
py gui_calculator.py
```
